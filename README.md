# Programar Cajeros

App para armar la programación mensual de turnos de cajeros. Es una PWA: se instala en la computadora y funciona sin internet.

- Link: https://cuadraditos-vp.github.io/porogramar-cajeros/
- Los datos (meses, preferencias, colores) están en Firebase, en el mismo proyecto que la app de cajeros. Las reglas están en `REGLAS-FIREBASE.md`.
- La lista de cajeros se trae de la app de cajeros (no hay nombres en este repositorio).
